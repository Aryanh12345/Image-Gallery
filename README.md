# 🖼️ Horizontal Scroll Image Gallery

A simple and interactive **Horizontal Scroll Image Gallery** built using **HTML, CSS, and JavaScript**.

The project allows users to browse through a collection of images horizontally using navigation controls, creating a smooth and interactive gallery experience.

## 🌐 Live Demo

👉 **[Visit Image Gallery](https://aryanh12345.github.io/Image-Gallery/)**

## 🚀 Features

- 🖼️ Horizontal image gallery
- ↔️ Smooth horizontal scrolling
- ⬅️ Previous image navigation
- ➡️ Next image navigation
- 🖱️ Interactive navigation buttons
- 🎨 Clean and simple user interface
- 📱 Responsive design
- ⚡ Lightweight and fast
- 💻 Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure of the gallery
- **CSS3** – Layout, styling, and scrolling effects
- **JavaScript** – Gallery navigation and interactions
